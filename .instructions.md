# 🛒 E-commerce Premium: FastAPI + React + TailwindCSS

## Contexto do Projeto
E-commerce profissional e moderno desenvolvido com:
- **Backend**: Python + FastAPI + SQLAlchemy + PostgreSQL
- **Frontend**: React + TypeScript + TailwindCSS + Framer Motion
- **Arquitetura**: REST API escalável com separação de responsabilidades
- **Design**: Premium, responsivo, acessível e otimizado

## Princípios de Desenvolvimento
1. **Código Production-Ready**: Limpo, documentado e pronto para produção
2. **Type Safety Total**: TypeScript strict + Python type hints
3. **Design System Consistente**: Tailwind com componentes reutilizáveis
4. **Segurança em Primeiro Lugar**: JWT, CORS, validação, proteção CSRF
5. **Performance**: Lazy loading, otimização de queries, caching
6. **Testes**: Cobertura 80%+ - unitários + integração
7. **UX Excelente**: Animações suaves, loading states, erro handling

## Instruções para Desenvolvimento

### Backend (FastAPI)
- Criar modelos bem estruturados com relacionamentos claros
- Usar Pydantic para validação de schemas
- Implementar middleware de tratamento de erros
- Documentar endpoints com docstrings e OpenAPI (Swagger)
- Usar dependency injection do FastAPI
- Implementar rate limiting e validação de permissões

### Frontend (React)
- Componentes funcionais com hooks
- Separar lógica de apresentação
- Implementar tratamento de erros e loading states
- Usar React Query ou SWR para gerenciamento de dados
- Validar formulários tanto no frontend quanto no backend
- Mobile-first responsive design com Tailwind

### Segurança
- Validar TODOS os inputs no backend
- Implementar CORS corretamente
- Usar HTTPS em produção
- Proteger rotas administrativas
- Implementar rate limiting
- Sanitizar outputs para XSS

### Qualidade de Código
- Usar linting (ESLint + Prettier no frontend, Flake8 + Black no backend)
- Nomenclatura clara: variáveis, funções, classes
- Evitar código duplicado
- Comentar lógica complexa
- Manter arquivos <= 300 linhas (média)

## Workflow para Implementação
1. **Planejamento**: Escrever schema de dados e endpoints antes de codificar
2. **Backend First**: Implementar API com testes antes do frontend
3. **Integração**: Conectar frontend com API
4. **Testes**: Testar casos feliz e cenários de erro
5. **Documentação**: README, guias de instalação, exemplos
6. **Deploy**: Preparar para produção (Docker, CI/CD)

## Ao Trabalhar Comigo
- Seja específico em requisitos: "Criar endpoint POST /api/products com validação X"

- Mantenha commits atômicos e descritivos
- Teste incrementalmente, não deixe tudo para o final
